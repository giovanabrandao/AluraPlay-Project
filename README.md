📁 AluraPlay-Project
Projeto da Alura para treinar responsividade, HTML e JavaScript



✨ Descrição
Recriação da interface do AluraPlay, com foco em design responsivo e estruturação 
de conteúdo utilizando HTML, CSS e JavaScript. Neste projeto, aprendi a adaptar 
layouts para diferentes tamanhos de tela, aplicar boas práticas de semântica 
e interação básica com scripts.


🛠 Tecnologias:

HTML5
CSS3
JavaScript
Mobile First / Responsividade
